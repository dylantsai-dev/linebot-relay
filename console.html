调用说明

所有接口使用 Bearer Token 认证，把 <TOKEN> 换成你的访问密钥。

示例

请求字段

字段说明
session必填。1–128 个字符，仅限字母、数字和 _ . : -，同一个 key 固定对应同一个 Codex 会话。
message有附件时可省略，默认“请查看附件。”。无附件 JSON 上限 1 MiB。
codex_session_id可选。把 key 绑定到已有的 Codex 会话 ID（8–64 位字母、数字、连字符）。
callback_url可选。HTTP/HTTPS 回调地址；带上后立即返回 202，完成后 POST 结果。

响应

同步：{"session":"my-session","codex_session_id":"…","reply":"你好"}
异步受理：{"accepted":true,"session":"my-session"}
成功回调：{"session":"…","codex_session_id":"…","reply":"…"}
失败回调：{"session":"…","error":"…"}

支持 multipart 的 file / files、JSON files（name、content_base64、mime）和 file_urls。默认最多 5 个文件，每个 20 MiB；超限返回 413。远程文件仅支持公网 HTTP/HTTPS，超时 30 秒，最多 3 次跳转。含附件请求上限约 141 MiB。

运行规则

同一个 key 的消息严格按顺序执行；全局并发 2；单条消息超时 10 分钟（返回 504）。回调超时 15 秒，不自动重试。

冒号在工作目录和历史文件名中会映射为下划线。删除会话只删除映射和消息历史，Codex 文件和工作目录保留。

新建会话

1–128 个字符，仅限 A–Z a–z 0–9 _ . : -

发送第一条消息后才会保存到服务端。

删除会话

只删除会话映射和消息历史，Codex 文件和工作目录会保留。此操作无法撤销。
